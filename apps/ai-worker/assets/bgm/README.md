# BGM 라이브러리

스타일 프리셋 → 태그 매핑으로 BGM을 자동 선택합니다 (`pipeline/music.py`).

## 디렉토리 구조

태그별 하위 디렉토리에 라이선스가 정리된 음원을 넣습니다.

```
assets/bgm/
  calm/     # 프리셋 '감성'
  upbeat/   # 프리셋 '여행'
  daily/    # 프리셋 '일상'
```

지원 확장자: `.m4a .mp3 .aac .wav .ogg .flac`
매칭 로직: 프리셋 태그 디렉토리에서 무작위 선택 → 없으면 전체에서 선택 → 그래도 없으면 BGM 없이 진행.

## 라이선스 주의

- **반드시 라이선스가 클리어된 음원만** 배치하세요 (상업적 사용 + SNS 업로드 허용).
- 실제 음원 파일은 git에 커밋되지 않습니다 (`.gitignore` 처리). 운영 배포 시 별도로 동기화하세요.
- 개발 환경에서는 파이프라인 검증용 합성 톤(placeholder)을 사용할 수 있습니다:
  `scripts/generate-dev-bgm.sh` 참고.
