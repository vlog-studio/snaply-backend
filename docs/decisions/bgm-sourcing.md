## 한 줄 요약

무비에 음악을 입히는 코드는 있지만 **쓸 수 있는 음원이 없다**(`assets/bgm/` 에는 README 만 있다).
음원을 어디서 가져올지 정해야 하고, 어느 경로든 "**사용자가 그 영상을 틱톡·인스타에 올려도 되는가**"가
핵심 조건이다. 이 조건이 빠지면 사용자 영상이 플랫폼에서 무음 처리되거나 내려간다.

## 쉬운 설명 — 왜 음원 라이선스가 까다로운가

- 우리가 음악을 "듣는" 게 아니라, 음악을 넣은 영상을 **사용자가 자기 이름으로 다시 배포**한다.
  일반적인 "상업 이용 가능" 만으로는 부족하고, **최종 사용자의 재배포**를 허용해야 한다.
- 유튜브·틱톡·인스타는 **Content ID** 같은 자동 음원 식별 시스템으로 저작권 주장을 붙인다.
  정당한 라이선스가 있어도 시스템이 모르면 클레임이 걸리므로, 면제(화이트리스트) 절차가 있는
  서비스인지가 중요하다.
- 우리는 만료된 무비를 나중에 **무료로 다시 만들어 주기**로 했다(MOV-16). 라이선스가 끝난 뒤의 재렌더가
  "기존 콘텐츠 사용"인지 "신규 제작"인지 계약마다 다르다. 이 조건은
  [movie-cleanup-after-export.md](movie-cleanup-after-export.md)에서 재생성을 유지할 때만 필요하다.

## 이 결정이 영향을 주는 곳

| 영역 | 무엇이 바뀌나 |
|---|---|
| 법률·약관 | 조달 경로별 계약 검토. 사용자 약관에 "음원은 앱 내 생성 영상에 한해 사용 가능" 같은 고지 |
| 서버 스키마 | `bgm_tracks` 테이블(트랙 ID·무드 태그·BPM·비트 그리드·라이선스 출처). `schema.prisma` 는 공유 파일 |
| 워커 | 현재 디렉터리에서 **무작위**로 고르므로 같은 레시피로 다시 만들면 음악이 달라진다(E-5). 트랙 ID 를 레시피에 고정해야 한다 |
| 파이프라인 검증 | 비트 싱크·덕킹·무드 매칭·whisper 자막 인식 재확인이 전부 실제 음원이 있어야 가능하다 |
| 비용 | 구독형 라이선스는 월 고정비, AI 생성은 건당 또는 월 구독, 커미션은 일시 비용 |

## 공통 검토 항목 — 어느 경로든 이 여섯 가지에 답이 있어야 한다

1. 상업 이용 허용
2. **최종 사용자의 소셜 업로드(재배포)** 허용
3. Content ID 클레임 면제 또는 화이트리스트 절차
4. 저작권 귀속 — 특히 AI 생성물은 국가별로 저작권이 성립하지 않을 수 있어, 제3자가 같은 음원을 자유롭게
   쓸 수 있는지(독점성)와 우리가 침해 주장을 받았을 때 서비스 측 면책 범위
5. 계약 종료 후 기존 콘텐츠 사용 유지 + **만료 무비 재생성**이 허용되는지
6. 학습 데이터 출처에 대한 서비스 측 보증(AI 생성만 해당)

## 선택지와 그 결과

### 선택지 A — AI 생성 음원 (회의 제안)

| 좋은 점 | 나쁜 점 |
|---|---|
| 무드·길이·BPM 을 원하는 대로 뽑을 수 있어 비트 그리드 만들기가 쉽다 | 저작권 귀속이 불명확한 국가가 있다. 서비스 약관이 재배포·Content ID 를 어떻게 다루는지 확인 없이는 못 쓴다 |
| 트랙 수를 늘리는 비용이 낮다 | 학습 데이터 침해 논란 시 우리 사용자 영상까지 영향받을 수 있다. 면책 조항 확인이 필요하다 |
| | 품질 편차가 있어 사람이 골라내는 큐레이션 작업이 필요하다 |

### 선택지 B — 상업 라이선스 구독 (Epidemic Sound · Artlist · Uppbeat 등)

| 좋은 점 | 나쁜 점 |
|---|---|
| 재배포·Content ID 화이트리스트 절차가 정립돼 있다 | 월 고정비. "앱에 내장해 사용자가 파생물을 만든다"는 형태는 **일반 크리에이터 플랜이 아닌 별도(엔터프라이즈/API) 계약**을 요구하는 경우가 많다 |
| 품질이 안정적 | 구독 종료 후 재생성 허용 여부를 협상해야 한다(항목 5) |

### 선택지 C — 작곡 커미션 / 매절 (buy-out)

| 좋은 점 | 나쁜 점 |
|---|---|
| 우리가 권리를 가져 항목 1~5 가 한 번에 해결된다 | 일시 비용이 크고 트랙 수가 적다(15~20트랙 확보에도 시간이 든다) |
| 제품 고유의 사운드 | 추가 트랙마다 비용 |

### 선택지 D — 무료·CC 라이선스 음원

| 좋은 점 | 나쁜 점 |
|---|---|
| 비용 0 | CC 는 저작자 표시 의무가 있어 영상마다 크레딧을 넣어야 하고, 비상업(NC) 조건이 붙은 것이 많다. Content ID 클레임에 대응할 주체가 없다 |

## 권장

**법적 검토 결과가 나오기 전에는 고르지 않는다**(회의 결정과 같다). 검토는 A 와 B 의 후보 각 2~3곳 약관을
위 여섯 항목으로 표 비교하는 형태로 하고, 결과에 따라 **A 또는 B 를 주력, 검증용 15~20트랙은 먼저 확보**
해 파이프라인 검증(E-5 포함)을 시작한다. D 는 기각.
