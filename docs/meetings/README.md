# 회의 문서

회의 안건과 결과를 담는다. 파일명은 `YYYY-MM-DD-<주제>.md`, 날짜가 안 잡힌 예정 회의는
`next-agenda.md`로 두었다가 날짜 확정 시 rename한다 ([doc-conventions.md](../doc-conventions.md)).

| 문서 | 내용 |
|---|---|
| [2026-08-31-dev-sync.md](2026-08-31-dev-sync.md) | 개발자 회의 — SNS 연동 상태(웹훅용 도메인), BGM·자막 방향, 영상/프로젝트/결과물 생애주기 제안, 에셋·관리자 페이지 |

회의에서 나온 미결 작업은 [backlog.md](../backlog.md)에만 올리고, 회의 문서는 그 항목을 가리킨다.
지난 회의·열리지 않은 회의의 제안 문서는 [docs/archive/](../archive/)에 있다.
