# 스펙 — 스냅 라이브러리

**작성일**: 2026-09-02
**상태**: 현행 — 스냅 촬영·보관 요구사항의 원천
**관련 문서**: [decisions/snap-source-of-truth.md](../decisions/snap-source-of-truth.md) · [decisions/storage-and-subscription-policy.md](../decisions/storage-and-subscription-policy.md) · [apps/mobile/docs/features/snaps.md](../../apps/mobile/docs/features/snaps.md) · 표기 규칙은 [README.md](README.md)

## 스냅 만들기

- **SNAP-1** `구현됨` — 스냅은 **0.5~5초의 짧은 클립**이다. 만드는 방법은 두 가지다:
  앱 카메라로 촬영하거나, 갤러리 영상에서 잘라낸다.
- **SNAP-2** `구현됨` — 촬영은 어느 탭에서든 중앙 촬영 버튼으로 바로 뷰파인더에 진입하고,
  길이(3초/5초)를 뷰파인더 안에서 고른 뒤 **누르고 있는 동안** 녹화한다. 촬영된 스냅은
  라이브러리에 저장되고, 위치를 알 수 있으면 촬영 장소가 함께 기록된다. 촬영 후에도
  뷰파인더에 남아 연속 촬영할 수 있다.
- **SNAP-3** `구현됨`(iOS 네이티브 트림 경로는 `부분` — [기능 문서](../../apps/mobile/docs/features/snap-extract.md) 참조) —
  갤러리 영상에서 필름스트립 위 드래그 창(0.5~5초)으로 구간을 골라 스냅으로 잘라낸다.
  잘라낸 스냅은 촬영 스냅과 동일하게 라이브러리에 들어간다.

## 라이브러리

- **SNAP-4** `구현됨` — 라이브러리는 스냅을 **날짜별로 묶어** 보여주고, 재생·선택·삭제를
  지원한다. 선택한 스냅으로 새 무비를 시작하거나 기존 무비에 추가할 수 있다.
- **SNAP-5** `구현됨` — 스냅 삭제는 연쇄적이다: 파일·썸네일·무비의 참조·메타데이터·서버
  동기화 상태가 함께 정리된다. 삭제된 스냅을 참조하던 무비는 그 컷을 잃는다.

## 서버 보관

방향: 스냅의 원천을 기기에서 서버로 전환한다 — [decisions/snap-source-of-truth.md](../decisions/snap-source-of-truth.md)

- **SNAP-6** `구현됨` — 로그인 상태에서 모든 스냅은 **백그라운드로 서버에 업로드**된다.
  사용자가 업로드를 직접 관리하지 않으며, 실패는 재시도되고 삭제는 서버에도 전파된다.
- **SNAP-7** `구현됨` — 클립 하나는 최대 **500MB**다. 초과 업로드는 등록되지 않는다.
- **SNAP-8** `구현됨` — 서버에 보관된 원본은 소유자만 접근할 수 있고, 재생 URL 은 시한부다.
  다른 사용자의 스냅은 존재 여부조차 알 수 없다.
- **SNAP-9** `결정·미구현` — 무료 사용자의 원본 스냅 서버 보관 한도는 **2GB** 다. 한도 초과 시
  전이 규칙(유예 → 읽기 전용)을 포함한 집행은 아직 없다. 보관 한도 확장은 구독으로 판다
  (크레딧과 분리 — [credits-and-payment.md](credits-and-payment.md) CRD-7).
- **SNAP-10** `결정·미구현` — 촬영 시각(`capturedAt`)은 서버에도 저장돼 서버가 시간 기반
  기능(그룹핑·추천)을 수행할 수 있어야 한다. 현재 촬영 시각은 앱만 안다.
- **SNAP-11** `보류` — 촬영 위치의 서버 저장은 프라이버시·약관 검토가 끝나기 전에는 하지
  않는다. 현재 위치는 기기에만 남는다.
