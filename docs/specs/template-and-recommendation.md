## 템플릿

- **TPL-1** `구현됨` — 템플릿은 무비의 **형태**다: 촬영 지시 슬롯 목록(레이블·힌트)과
  스타일·BGM. 슬롯의 레이블은 사람에게 주는 촬영 지시이지, 채워진 스냅의 내용에 대한
  주장이 아니다.
- **TPL-2** `구현됨` — 템플릿 카탈로그는 **서버가 소유**한다. 앱은 카탈로그를 캐시하고,
  서버가 죽어도 내장 폴백으로 템플릿 화면이 동작한다. 앱이 모르는 스타일의 템플릿은
  앱이 건너뛴다.
- **TPL-3** `구현됨` — 템플릿으로 시작하면 앱이 라이브러리에서 **한 번의 외출**을 찾아 슬롯을
  즉시 채운다(로컬 매칭 — 촬영 시각·좌표만 사용). 빈 슬롯은 `지금 찍기`로 바로 촬영해
  채울 수 있고, 결과는 일반 무비 초안이 되어 자유 편집을 거친다.

## 스냅 자동 추천 (서버)

- **REC-1** `구현됨` — 서버 추천은 스냅 내용 분석을 근거로 각 슬롯에 넣을 스냅을 제안한다.
  **앱은 추천을 기다리지 않는다** — 로컬 매칭이 먼저 화면을 채우고, 추천은 **사용자가
  손대지 않은 슬롯에만** 얹힌다. 추천이 느리거나 실패해도 템플릿 화면은 그대로 동작한다.
- **REC-2** `구현됨` — 넣을 만한 후보가 없는 슬롯은 **비워 둔다.** 못 쓸 스냅으로 채우지
  않는다. 추천 점수는 슬롯 적합도이지 스냅 내용에 대한 주장이 아니며, 분석의 모델 출력
  (요약·주제 등)은 사용자에게 노출하지 않는다.
- **REC-3** `구현됨` — 추천은 **크레딧을 차감하지 않는다.** 비용은 상한으로 막는다:
  후보 1회 12개, 사용자당 최근 24시간 20회 (잠정값 — 단가 실측 후 재조정).
- **REC-4** `보류` — 추천(과 그것이 유발하는 분석)은 **기본 꺼짐**이다. 생산 스냅의 프레임을
  외부 모델로 보내는 경로이므로, 약관·개인정보처리방침의 법무 검토가 끝나기 전에는 켜지
  않는다([backlog.md](../backlog.md) A-3·A-6). 꺼져 있는 동안 모든 사용자는 로컬 매칭만 본다.

## 스냅 내용 분석

- **ANA-1** `구현됨` — 분석은 **명시적으로 요청될 때만** 돈다. 업로드했다고 자동 분석하지
  않는다 — 대부분의 스냅은 편집에 쓰이지 않으므로, 쓰일 후보가 정해진 시점에만 비용을 쓴다.
- **ANA-2** `구현됨` — 분석 결과(주제·장소·사물·행동·분위기·편집 사용 가능 여부)는 **자동
  편집·추천의 내부 입력**이며 사용자에게 보여주는 문구가 아니다.
- **ANA-3** `구현됨` — 외부 모델로 보내는 것은 **대표 프레임 최대 4장**뿐이다. 오디오는
  보내지 않고, 영상이 삭제되면 분석 결과도 함께 파기된다. 이 전송 범위는 개인정보처리방침
  문구와 테스트로 고정돼 있다.
- **ANA-4** `구현됨` — 같은 영상에 대한 분석 요청은 멱등하다(버전당 한 번). 분석 실패는
  원본 영상에 어떤 영향도 주지 않으며, 재시도 가능한 실패만 다시 돈다.
